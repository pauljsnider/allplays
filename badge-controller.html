Valid for 30 days. This file authorizes score changes for the selected team. Keep it private and copy it to your badge as described below.

Install the complete AllPlays Scoreboard app. Copy controller.json into apps/allplays_scoreboard/ on the badge USB drive. Set Wi-Fi in badge Settings, eject, reset and open the app.

Close or pause other trackers before taking control. Player statistics, Diamond scorebooks and shared-schedule games are not supported in this first version. Release control before returning to the regular tracker, then reload that tracker to obtain the current score.
